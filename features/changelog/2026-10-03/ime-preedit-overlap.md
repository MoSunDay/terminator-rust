# 拼音预编辑与已有文字重叠

预编辑原先直接画在终端旧字上，组合位置固定也会让下一段预编辑盖住上一笔延迟回显的已提交内容。

- 先绘制终端背景色的不透明底色，再画预编辑；覆盖范围按单双宽单元格计算，取消后恢复终端原始画面。
- 位置始终跟随有效终端光标；隐藏或过渡帧才回退到记住的位置。平台 IME 保持不中断，重命名交接沿用原来的保护。
- 可见 IBus 原生面板加入隔离端到端测试，新增延迟回显、隐藏光标、换行、屏幕底部和缩放边界；失败保留并使 CI 失败。
- 发布脚本改用 SHA256 独立目录，切换前持久化回滚记录，并验证安装、重试、崩溃和恢复；同版本号不再覆盖旧二进制。

## 验收

- 全仓 404 项 Rust 测试、fmt、Clippy、aarch64-apple-darwin 全目标交叉检查、release 构建通过。
- CJK、鼠标/键盘回归、IME 提交/取消/重命名/英文切换/退出通过；M3b 的 138 个旧字像素遮挡与恢复通过；M3c 的 183 个已提交红色像素在延迟 1.2 秒回显后全部可见。
- 7 项部署测试通过。真实包在私有 Xvfb 中安装、启动、恢复到旧布局目录后再启动，实际 executable 路径及 IPC/PTY 检查通过；未执行生产发布。

## 尚未闭环

P1：X11 + IBus 原生候选窗在屏幕底部向上弹出时遮挡当前输入行，M3d 的底部和换行两例失败。winit 0.30 只传点、IBus XIM 只读 spot，均缺少整行矩形信息；libX11 ≥ 1.8.2 能恢复坐标更新，但不能修复这个边界。没有添加猜测候选窗高度的坐标补丁。

macOS 原生候选窗未实机验收，可用 SSH 别名连接超时；Linux 结果与交叉编译不能替代。因此当前候选未达到稳定上线标准。
